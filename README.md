# MCA203P Lab Sheet-01 — Object Oriented Programming Using Java

This folder contains separate Java programs for all 20 questions from Lab Sheet-01.

## Compile and run

Open a terminal in this folder and use:

```text
javac 01_StudentInfo.java
java StudentInfo
```

For each program, the Java class name matches the class name in the file.

## Questions covered

01. Display name, age, and college
02. Arithmetic operations
03. Even or odd
04. Relational operators
05. Explicit type casting
06. ASCII value
07. Divisible by 3 and 5
08. Vowel or consonant
09. Marks, percentage, and pass/fail
10. Greatest of two numbers
11. Largest of three numbers
12. Leap year
13. Positive, negative, or zero
14. Character classification
15. 3-digit Armstrong number
16. Income tax by given slabs
17. Palindrome number
18. Prime number
19. Operator-based calculator
20. Marriage eligibility using nested if-else
